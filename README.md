# CheckChoice

เว็บแอปตรวจข้อสอบปรนัยจากรูปถ่ายกระดาษคำตอบ ใช้ได้บน Android, iPhone, iPad และคอมพิวเตอร์ผ่านเบราว์เซอร์ ไม่ต้องติดตั้งจาก Store (เพิ่มไว้ที่หน้าจอหลักได้แบบ PWA และใช้งานออฟไลน์ได้หลังเปิดครั้งแรก)

## ทำอะไรได้บ้าง

- **คลังเฉลยตามรายวิชา** สร้างชุดข้อสอบ (รหัสวิชา ชื่อวิชา ชื่อการสอบ) ถ่ายรูปใบเฉลยหรือแตะเลือกเฉลยเอง และเก็บภาพใบเฉลยต้นฉบับไว้
- **จำนวนข้อยืดหยุ่น** เช่น สอบ 40 ข้อในกระดาษ 60 ข้อ แอปตรวจเฉพาะข้อ 1–40 และเสนอจำนวนข้อจากใบเฉลยให้อัตโนมัติ
- **ตรวจได้ 2 แบบ** ถ่ายรูป/เลือกรูป หรือกล้องสดที่จับกรอบตารางและถ่ายเองเมื่อภาพนิ่ง
- **เลขที่นักศึกษา** เลือกจากรายการ 1–100 เพิ่มได้ด้วยปุ่ม + และเลื่อนไปเลขที่ถัดไปที่ยังไม่ตรวจให้เอง
- **ข้อที่ต้องให้อาจารย์ยืนยัน** ระบายทึบยกเลิกแล้วกากบาทช่องใหม่, ตอบหลายช่อง, หรือไม่ได้ตอบ จะไฮไลต์สีเหลือง แสดงคะแนนชั่วคราวโดยนับข้อเหล่านี้เป็นศูนย์ และบันทึกได้เมื่อยืนยันครบ
- **ทนต่อการถ่ายจริง** ภาพเอียง ถ่ายเฉียง แสงไม่เท่ากัน ภาพกลับหัวหรือหมุน 90° แอปหมุนกลับให้เอง
- **ส่งออก** Excel (คะแนน + คำตอบรายข้อ + จำนวนคนตอบถูกแต่ละข้อ) และ PDF ผ่านหน้าพิมพ์ของเบราว์เซอร์
- **สำรอง/กู้คืน** ข้อมูลทั้งหมดเป็นไฟล์เดียว ใช้ย้ายเครื่องได้
- **ส่งชุดข้อสอบไปเครื่องอื่น** เช่น สร้างเฉลยบนคอมพิวเตอร์แล้วตรวจด้วยมือถือ: กด "ส่งไปมือถือ / เครื่องอื่น" แล้วสแกน QR code ด้วยกล้องมือถือ หรือส่งลิงก์ทาง LINE/อีเมล (ลิงก์มีเฉพาะรายวิชาและเฉลย ไม่มีรูปหรือคะแนน)

## ความเป็นส่วนตัว

ประมวลผลภาพด้วย OpenCV.js ในเครื่องของผู้ใช้ทั้งหมด รูปกระดาษและคะแนนเก็บใน IndexedDB ของเบราว์เซอร์ ไม่ถูกส่งไปที่เซิร์ฟเวอร์ใด เซิร์ฟเวอร์ (Vercel) ทำหน้าที่ส่งไฟล์แอปเท่านั้น

บน iPhone ควรเปิดจากไอคอนบนหน้าจอหลัก เพราะข้อมูลของเว็บที่เปิดใน Safari ธรรมดาอาจถูกล้างเมื่อไม่ได้ใช้นาน และควรดาวน์โหลดไฟล์สำรองเป็นประจำ

## ปัญหาที่พบบ่อย

**iPhone/iPad ขึ้นว่าเบราว์เซอร์ใช้ไม่ได้ (เดิมขึ้น `Can't find variable: indexedDB`)** เกิดจากโหมดล็อกดาวน์ (Lockdown Mode) ซึ่งปิด IndexedDB และ WebAssembly ใน Safari ต้องปิดทั้งเครื่องที่ การตั้งค่า → ความเป็นส่วนตัวและความปลอดภัย → โหมดล็อกดาวน์ → ปิดและรีสตาร์ท การยกเว้นเฉพาะเว็บไซต์ไม่พอ เพราะ iOS 17.4 ขึ้นไปยังบล็อก WebAssembly อยู่ แอปจะแสดงหน้าอธิบายวิธีแก้นี้เองเมื่อพบปัญหา

## แบบฟอร์มที่รองรับ

ตอนนี้รองรับกระดาษคำตอบแบบ **กากบาทในช่องตาราง 60 ข้อ (4 ชุด × 15 ข้อ) ตัวเลือก A–E** ตามตัวอย่าง แบบฟอร์มกำหนดเป็นค่าตั้งค่าใน `js/omr/core.js` (`TEMPLATES`) จึงเพิ่มแบบตารางอื่นได้โดยไม่ต้องแก้อัลกอริทึม

## โครงสร้าง

```
index.html, css/app.css      หน้าแอป
js/omr/core.js               อัลกอริทึมอ่านกระดาษ (ใช้ได้ทั้งในเบราว์เซอร์และ Node)
js/omr/worker.js, client.js  ประมวลผลภาพใน Web Worker
js/views/*.js                หน้าจอต่าง ๆ
js/capture.js                ถ่ายรูป / กล้องสด
js/db.js, js/store.js        เก็บข้อมูลใน IndexedDB
js/export.js                 Excel และไฟล์สำรอง
js/transfer*.js              ส่งชุดข้อสอบไปเครื่องอื่นด้วยลิงก์/QR code
js/env.js                    ตรวจความพร้อมของเบราว์เซอร์และหน้าวิธีแก้
sw.js, manifest.webmanifest  PWA และการใช้งานออฟไลน์
vendor/                      OpenCV.js 4.12 (Apache 2.0), SheetJS 0.18.5 (Apache 2.0), qrcode-generator 2.0.4 (MIT)
fonts/                       IBM Plex Sans Thai Looped (SIL OFL 1.1)
tests/                       ชุดทดสอบและรูปตัวอย่าง (เบลอส่วนหัวที่มีชื่อแล้ว)
```

## พัฒนาและทดสอบ

ไม่มีขั้นตอน build เปิดด้วยเว็บเซิร์ฟเวอร์ใดก็ได้ เช่น

```bash
npm run serve        # http://localhost:8080 (กล้องใช้ได้บน localhost หรือ HTTPS เท่านั้น)
npm install          # ติดตั้งเครื่องมือทดสอบ
npm test             # ทดสอบอัลกอริทึมกับรูปกระดาษจริง (เฉลย, กระดาษเปล่า, นักศึกษา 3 แผ่น, ภาพหมุน)
npm run test:e2e     # ทดสอบทั้งระบบบน Chromium (ต้องติดตั้งเบราว์เซอร์ของ Playwright)
```

## Deploy

เชื่อม repo นี้กับโปรเจกต์บน Vercel (Framework: Other, ไม่มี build command, output คือโฟลเดอร์หลัก) ทุกครั้งที่ push ขึ้น `main` จะ deploy ใหม่อัตโนมัติ ส่วนหัว HTTP ตั้งไว้ใน `vercel.json`
