# CheckChoice

เว็บแอปตรวจข้อสอบปรนัยจากรูปถ่ายกระดาษคำตอบ ใช้ได้บน Android, iPhone, iPad และคอมพิวเตอร์ผ่านเบราว์เซอร์ ไม่ต้องติดตั้งจาก Store (เพิ่มไว้ที่หน้าจอหลักได้แบบ PWA และใช้งานออฟไลน์ได้หลังเปิดครั้งแรก)

## ทำอะไรได้บ้าง

- **หน้าแรกเลือกได้ 2 ทาง** "เปิดจากคลังเฉลย" (ค้นหาจากรหัสวิชา ชื่อวิชา หรือชื่อการสอบ จัดกลุ่มตามรายวิชา) หรือ "สร้างเฉลยใหม่" และมีชุดที่ใช้ล่าสุดให้กดตรวจต่อได้ทันที
- **คลังเฉลยตามรายวิชา** สร้างชุดข้อสอบ (รหัสวิชา ชื่อวิชา ชื่อการสอบ) ถ่ายรูปใบเฉลยหรือแตะเลือกเฉลยเอง และเก็บภาพใบเฉลยต้นฉบับไว้
- **แบบฟอร์มกระดาษคำตอบหลายแบบ** มีแบบสำเร็จรูป 60, 100 และ 120 ข้อ และเพิ่มแบบที่มีข้อมากขึ้นเองได้จากรูปกระดาษเปล่า (ดูหัวข้อแบบฟอร์มด้านล่าง) พร้อมพิมพ์กระดาษคำตอบเปล่าขนาด A4 จากแอป
- **เฉลยหลายคำตอบในข้อเดียว** (ตัวเลือกในหน้าเฉลย) แตะเลือกเฉลยได้หลายช่องในข้อเดียว เลือกกติกาได้ 2 แบบ: "ตอบตัวเลือกใดก็ได้ที่เฉลยไว้" (นักศึกษากากบาทช่องเดียวที่อยู่ในเฉลยก็ได้คะแนน) หรือ "ต้องกากบาทครบทุกตัวเลือกที่เฉลย" (กากบาทหลายช่องได้ ต้องครบและไม่เกิน) ข้อที่เฉลยช่องเดียวตรวจแบบเดิม ถ่ายใบเฉลยที่กากบาทหลายช่องได้ และเปลี่ยนกติกาภายหลังแล้วคะแนนคิดใหม่ให้
- **จำนวนข้อยืดหยุ่น** เช่น สอบ 40 ข้อในกระดาษ 60 ข้อ แอปตรวจเฉพาะข้อ 1–40 และเสนอจำนวนข้อจากใบเฉลยให้อัตโนมัติ
- **ตรวจได้ 2 แบบ** ถ่ายรูป/เลือกรูป หรือกล้องสดที่จับกรอบตารางและถ่ายเองเมื่อภาพนิ่ง
- **เลขที่นักศึกษา** เลือกจากรายการ 1–100 เพิ่มได้ด้วยปุ่ม + และเลื่อนไปเลขที่ถัดไปที่ยังไม่ตรวจให้เอง
- **ข้อที่ต้องให้อาจารย์ยืนยัน** ระบายทึบยกเลิกแล้วกากบาทช่องใหม่, ตอบหลายช่อง, หรือไม่ได้ตอบ จะไฮไลต์สีเหลือง แสดงคะแนนชั่วคราวโดยนับข้อเหล่านี้เป็นศูนย์ และบันทึกได้เมื่อยืนยันครบ
- **ทนต่อการถ่ายจริง** ภาพเอียง ถ่ายเฉียง แสงไม่เท่ากัน ภาพกลับหัวหรือหมุน 90° แอปหมุนกลับให้เอง
- **ส่งออก** Excel (คะแนน + คำตอบรายข้อ + จำนวนคนตอบถูกแต่ละข้อ) และ PDF ผ่านหน้าพิมพ์ของเบราว์เซอร์
- **สำรอง/กู้คืน** ข้อมูลทั้งหมดเป็นไฟล์เดียว ใช้ย้ายเครื่องได้
- **ลบชุดข้อสอบที่ไม่ใช้แล้ว** ปุ่มถังขยะท้ายแถวของแต่ละชุด (คลังเฉลยและหน้าแรก) หรือลบทั้งรายวิชาในคลังเฉลย ลบผลตรวจและรูปทั้งหมดของชุดนั้นไปด้วย คลังเฉลยบอกขนาดพื้นที่ที่แต่ละชุดใช้ และกล่องยืนยันบอกว่าจะได้พื้นที่คืนเท่าไร
- **ส่งชุดข้อสอบไปเครื่องอื่น** เช่น สร้างเฉลยบนคอมพิวเตอร์แล้วตรวจด้วยมือถือ: ที่เครื่องต้นทางกด "ส่งไปมือถือ / เครื่องอื่น" จะมี QR code ขึ้นมา (แตะเพื่อขยายเต็มจอได้) หรือส่งลิงก์ทาง LINE/อีเมล (มีเฉพาะรายวิชา เฉลย และโครงแบบฟอร์มที่เพิ่มเอง ไม่มีรูปหรือคะแนน)
- **รับชุดข้อสอบด้วยการสแกน QR code ในแอป** หน้าแรก → "รับจากเครื่องอื่น" (หรือปุ่ม QR ในคลังเฉลย) เปิดกล้องในแอปแล้วเล็งที่ QR code ของเครื่องต้นทาง สแกนติดแล้วไปหน้านำเข้าเอง ถ้าใช้กล้องสดไม่ได้ (เช่น iPhone โหมดล็อกดาวน์) ถ่ายรูปหรือเลือกภาพหน้าจอที่มี QR code แทนได้ และวางลิงก์ที่ได้ทาง LINE/อีเมลได้ในหน้าเดียวกัน ชุดข้อสอบจึงเข้าแอปที่ใช้ตรวจโดยตรง ไม่ไปอยู่ในเบราว์เซอร์อื่น
- **ข้อมูลสำหรับ Train** ทุกแผ่นที่ตรวจและยืนยันแล้วเก็บภาพตารางคู่กับคำตอบที่อาจารย์ยืนยัน ส่งออกเป็นไฟล์ .zip ไว้ฝึกโมเดลอ่านกระดาษภายหลัง (ดูหัวข้อด้านล่าง)
- **ใช้ได้แม้ iPhone เปิดโหมดล็อกดาวน์** แอปสลับไปใช้ที่เก็บข้อมูลสำรองและตัวอ่านภาพที่เขียนด้วย JavaScript ล้วนให้เอง (ดูหัวข้อปัญหาที่พบบ่อย)

## ความเป็นส่วนตัว

ประมวลผลภาพในเครื่องของผู้ใช้ทั้งหมด (OpenCV.js หรือตัวอ่านภาพสำรอง) รูปกระดาษและคะแนนเก็บในที่เก็บของเบราว์เซอร์ (IndexedDB หรือ localStorage/Cache Storage ในโหมดสำรอง) ไม่ถูกส่งไปที่เซิร์ฟเวอร์ใด เซิร์ฟเวอร์ (Vercel) ทำหน้าที่ส่งไฟล์แอปเท่านั้น

บน iPhone ควรเปิดจากไอคอนบนหน้าจอหลัก เพราะข้อมูลของเว็บที่เปิดใน Safari ธรรมดาอาจถูกล้างเมื่อไม่ได้ใช้นาน และควรดาวน์โหลดไฟล์สำรองเป็นประจำ

## ปัญหาที่พบบ่อย

**iPhone/iPad ที่เปิดโหมดล็อกดาวน์ (Lockdown Mode)** โหมดนี้ปิด IndexedDB (ตั้งแต่ iOS 17), WebAssembly, JIT และกล้องสด (getUserMedia) ใน Safari เดิมแอปจึงขึ้น `Can't find variable: indexedDB` ตั้งแต่เวอร์ชัน 1.3.0 แอปทำงานต่อได้เองแบบจำกัด:

- เก็บข้อมูลใน localStorage และรูปใน Cache Storage แทน IndexedDB (จุได้น้อยกว่า ควรดาวน์โหลดไฟล์สำรองหลังตรวจเสร็จ)
- อ่านกระดาษด้วยตัวอ่านภาพสำรอง `js/omr/cvlite.js` (เลียนแบบฟังก์ชัน OpenCV ที่ใช้ด้วย JavaScript ล้วน) ผลเท่ากับ OpenCV ในรูปทดสอบทุกรูป แต่ช้ากว่า: ราว 5 วินาทีต่อแผ่นเมื่อจำลองแบบไม่มี JIT
- ไม่มีกล้องสด ใช้ปุ่มถ่ายรูปแทน

ถ้าต้องการให้ทำงานเต็มความสามารถโดยไม่ปิดโหมดล็อกดาวน์ทั้งเครื่อง ให้ยกเว้นเฉพาะเว็บนี้: ใน Safari แตะปุ่มเมนูหน้าเว็บ (aA) ข้างช่องที่อยู่เว็บ → การตั้งค่าเว็บไซต์ (Website Settings) → ปิดโหมดล็อกดาวน์ หน้าเว็บจะโหลดใหม่ และข้อมูลที่บันทึกไว้ในที่เก็บสำรองจะย้ายเข้า IndexedDB ให้เอง ถ้า iOS รุ่นที่ใช้ยังปิด WebAssembly แม้ยกเว้นเว็บแล้ว ([WebKit bug 273824](https://bugs.webkit.org/show_bug.cgi?id=273824)) แอปก็ยังใช้ตัวอ่านภาพสำรองต่อได้ หน้าตั้งค่า → การทำงานบนเครื่องนี้ บอกว่าตอนนี้ใช้โหมดไหนอยู่

ถ้าเบราว์เซอร์ไม่ให้เว็บเก็บข้อมูลเลย (เช่น ปิดกั้นคุกกี้ทั้งหมด) แอปจะแสดงหน้าอธิบายวิธีแก้

**iPhone: สแกน QR code ด้วยแอปกล้องแล้วชุดข้อสอบไม่ขึ้นในแอป** แอปที่เพิ่มไว้บนหน้าจอโฮมเก็บข้อมูลแยกจาก Safari ส่วนลิงก์จากแอปกล้องจะเปิดใน Safari ให้สแกนจากในแอปแทน (หน้าแรก → รับจากเครื่องอื่น) ถ้าเปิดลิงก์ใน Safari ไปแล้ว หน้านำเข้าจะเตือนและมีปุ่มคัดลอกลิงก์ไปวางในแอป

**สแกน QR code ไม่ติด** ขยับมือถือเข้าใกล้ให้ QR code เต็มกรอบ เพิ่มความสว่างหน้าจอเครื่องต้นทาง หรือแตะที่ QR code บนเครื่องต้นทางเพื่อขยายเต็มจอ ถ้ายังไม่ได้ ใช้ปุ่มถ่ายรูป QR code หรือส่งลิงก์ทาง LINE แล้ววางในหน้ารับจากเครื่องอื่น

## แบบฟอร์มที่รองรับ

รองรับกระดาษคำตอบแบบ **กากบาทในช่องตาราง** มีหัวตาราง (A B C … / ก ข ค …) และคอลัมน์เลขข้อ

| แบบฟอร์ม | โครงตาราง | ตัวเลือก |
|---|---|---|
| 60 ข้อ (ตามกระดาษตัวอย่าง) | 4 ชุด × 15 ข้อ | A–E |
| 100 ข้อ | 5 ชุด × 20 ข้อ | A–E |
| 120 ข้อ | 4 ชุด × 30 ข้อ | A–D |

**เพิ่มแบบฟอร์มเอง** ที่หน้าแรก → เครื่องมือ → แบบฟอร์มกระดาษคำตอบ → เพิ่มแบบฟอร์ม แล้วถ่ายรูปกระดาษคำตอบเปล่า แอปนับจำนวนชุด ข้อต่อชุด ตัวเลือก (2–8) และแถวหัวตารางให้ ตรวจผังที่แสดงเลขข้อทับบนรูปแล้วแก้ตัวเลขได้ (เลขข้อเรียงลงตามคอลัมน์หรือเรียงไปทางขวาทีละแถว) รวมได้สูงสุด 300 ข้อ เมื่อบันทึกแล้วเลือกแบบฟอร์มนี้ได้ตอนสร้างเฉลยใหม่ และพิมพ์กระดาษเปล่าของแบบฟอร์มนี้ได้ด้วย

ชุดข้อสอบเก็บโครงตารางไว้ในตัวเอง ลบแบบฟอร์มทีหลังก็ยังตรวจชุดเดิมได้ และเมื่อส่งชุดข้อสอบไปเครื่องอื่น โครงแบบฟอร์มที่เพิ่มเองจะติดไปด้วย

แบบฟอร์มสำเร็จรูปกำหนดไว้ใน `js/omr/core.js` (`TEMPLATES`) ส่วนการนับโครงตารางจากรูปอยู่ที่ `inferTemplate()` ในไฟล์เดียวกัน

## ข้อมูลสำหรับ Train

หน้าแรก → เครื่องมือ → ข้อมูลสำหรับ Train → ดาวน์โหลดชุดข้อมูล ได้ไฟล์ `checkchoice-dataset-YYYY-MM-DD.zip` ประกอบด้วย

- `images/*.jpg` ภาพตารางคำตอบที่ดัดตรงแล้ว (เฉพาะตาราง ไม่มีหัวกระดาษที่เขียนชื่อ) จากกระดาษนักศึกษา ใบเฉลย และกระดาษเปล่าของแบบฟอร์มที่เพิ่มเอง
- `dataset.json` (`format: "checkchoice-dataset"`, `version: 1`) ตำแหน่งเส้นตาราง `xs`/`ys` ของแต่ละภาพ โครงแบบฟอร์ม และรายข้อ: คำตอบที่ยืนยัน ช่องที่ระบายยกเลิก ธงที่แอปตั้ง ข้อที่อาจารย์แก้ และค่าหมึกที่วัดได้ (ใช้เฉพาะข้อที่ `confirmed: true`)

ตัดเป็นภาพทีละช่องแยกตามป้ายด้วย

```bash
python3 tools/make_cells.py checkchoice-dataset-2026-10-22.zip cells/ --size 64
# cells/mark, cells/blank, cells/cancelled และ cells/cells.csv
```

## โครงสร้าง

```
index.html, css/app.css      หน้าแอป
js/omr/core.js               อัลกอริทึมอ่านกระดาษ (ใช้ได้ทั้งในเบราว์เซอร์และ Node)
js/omr/worker.js, client.js  ประมวลผลภาพใน Web Worker (เลือก OpenCV.js หรือตัวอ่านสำรองให้เอง)
js/omr/cvlite.js             ตัวอ่านภาพสำรองแบบ JavaScript ล้วน สำหรับเบราว์เซอร์ที่ปิด WebAssembly
js/views/*.js                หน้าจอต่าง ๆ (หน้าแรก คลังเฉลย แบบฟอร์ม ตรวจ ผลคะแนน ข้อมูล Train ตั้งค่า)
js/capture.js                ถ่ายรูป / กล้องสด
js/db.js, js/store.js        เก็บข้อมูลใน IndexedDB หรือที่เก็บสำรอง (ชุดข้อสอบ ผลตรวจ รูป แบบฟอร์มที่เพิ่มเอง)
js/template-draw.js          วาดผังแบบฟอร์มและเลขข้อ
js/training.js               รวบรวมและส่งออกชุดข้อมูลสำหรับ Train
js/delete-ui.js              ลบชุดข้อสอบ/ทั้งรายวิชา พร้อมบอกพื้นที่ที่ได้คืน
js/export.js                 Excel และไฟล์สำรอง
js/transfer*.js              ส่งชุดข้อสอบไปเครื่องอื่นด้วยลิงก์/QR code (ลิงก์แบบย่อ: JSON บีบอัดด้วย deflate เขียนเป็น
                             base32 ขึ้นต้นด้วย "2" ใช้โหมด Alphanumeric ของ QR ได้ ลิงก์แบบเดิมก่อน 1.6.0 ยังรับได้)
js/qr-scan.js, qr-worker.js  อ่าน QR code จากกล้อง/รูปภาพ (BarcodeDetector ของเบราว์เซอร์ถ้ามี ไม่เช่นนั้น jsQR ใน Web Worker)
js/env.js                    ตรวจความสามารถของเบราว์เซอร์ แจ้งโหมดจำกัด และหน้าวิธีแก้
sw.js, manifest.webmanifest  PWA และการใช้งานออฟไลน์
vendor/                      OpenCV.js 4.12 (Apache 2.0), SheetJS 0.18.5 (Apache 2.0), qrcode-generator 2.0.4 (MIT), fflate 0.8.3 (MIT),
                             jsQR 1.4.0 (Apache 2.0)
fonts/                       IBM Plex Sans Thai Looped (SIL OFL 1.1)
tools/make_cells.py          ตัดภาพทีละช่องจากชุดข้อมูลที่ส่งออก
tests/                       ชุดทดสอบและรูปตัวอย่าง (รูปจริงเบลอส่วนหัวที่มีชื่อแล้ว)
tests/synth/make_sheets.py   สร้างรูปกระดาษ 100/120 ข้อจำลองการถ่ายด้วยมือถือ สำหรับทดสอบ
```
